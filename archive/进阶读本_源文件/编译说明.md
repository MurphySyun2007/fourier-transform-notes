# 编译说明

## 环境

- XeLaTeX（TeX Live 2025/2026 或 MacTeX 均可）
- 中文字体：**Songti SC**、**Heiti SC**（macOS 自带）。
  换到别的系统时，只要把 `main.tex` 开头这三行改成该系统里有的字体即可：

  ```latex
  \setCJKmainfont{Songti SC}[BoldFont={Songti SC Bold}]
  \setCJKsansfont{Heiti SC Medium}
  \setCJKfamilyfont{zhhei}{Heiti SC Medium}
  ```

- 依赖宏包：ctex, amsmath, amssymb, amsthm, mathtools, mathrsfs, geometry,
  xcolor, tcolorbox, booktabs, longtable, array, tabularx, multirow,
  enumitem, tikz, pgfplots, fancyhdr, hyperref（TeX Live 完整安装都自带）。

## 编译

```bash
xelatex main.tex
xelatex main.tex     # 第二遍生成目录与交叉引用
```

产物：`main.pdf`，111 页。

## 文件结构

| 文件 | 内容 |
|---|---|
| `main.tex` | 导言区、封面、目录、章节装配 |
| `ch0.tex` | 第 0 章 导读：六期到底在讲什么 |
| `ep01.tex` … `ep06.tex` | 第 1–6 章，对应 EP01–EP06 |
| `ch7.tex` | 第 7 章 把六集缝起来 + 制作落地 |
| `appendix.tex` | 附录 A 公式总表 / B 能说不能说 / C 符号术语 / D 练习详解 |

## 改版提示

- 章节顺序在 `main.tex` 末尾的 `\input` 段；用 `\IfFileExists` 包着，删掉某一章也不会编译报错。
- 统一约定（$\omega$、$2\pi$ 位置、无共轭配对）只在 `main.tex` 导言区和各章首次出现处各写一次；
  若要换约定，附录 A 的换算表也要一起改。
- 四个提示盒环境：`ideabox`（蓝）、`warnbox`（红）、`quizbox`（绿）、`scriptbox`（橙）、`notebox`（灰）。
